NuxDroid Package Repository

Custom package repository for NuxDroid (aarch64).

Usage

# Add to sources.list:
deb [trusted=yes] https://mrzgamingv20-cyber.github.io/nuxdroid-packages aarch64 main
# Then:
pkg update
pkg install nuxdroid-bootstrap

Available Packages

  • nuxdroid-bootstrap 1.0.0 (meta-package for base system)
  • hello-nux 1.0.0
